divisi. Di luar organisasi, membangun dan menjalankan PernahGa, sebuah SaaS

percobaan.

Fokus utama saat ini ada di tiga arena: kuliah, organisasi, dan produk sendiri,
sambil tetap menerima proyek freelance untuk menjaga jam terbang di dunia
kerja nyata.
