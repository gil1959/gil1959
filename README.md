Menjabat sebagai Sekretaris Departemen Penelitian dan Teknologi (Penristek) di HIMATIF, mengurus dokumentasi, koordinasi program kerja, dan kegiatan lintas divisi. Di luar organisasi, membangun dan menjalankan PernahGa, sebuah SaaS berbasis AI yang sudah punya pengguna berbayar sungguhan, bukan sekadar proyek percobaan.

Fokus utama saat ini ada di tiga arena: kuliah, organisasi, dan produk sendiri, sambil tetap menerima proyek freelance untuk menjaga jam terbang di dunia kerja nyata.
